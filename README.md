## 🏛️ Repository Overview
This repository contains the complete, reproducible, and evidence-grounded implementation of **RYTT Sovereign Semiotics** (Radial Yett-Topology Tokenization):

1. **`monograph/`**: The complete, camera-ready 15-page single-column master treatise in LaTeX and compiled PDF.
2. **`src/rytt/`**: The core Python reference compiler, trie tokenizer, and lossless decompiler.
3. **`proofs/`**: Formal machine-checked Lean 4 theorem files proving left-inverse bijections ($\mathcal{D}(\mathcal{C}(S)) \equiv S$) with 0 axioms and 0 sorries.
4. **`renderers/`**: Interactive, real-time WebGL/HTML5 3D holonomic polygon visualizers and Blakean typographical engines.
5. **`benchmarks/`**: Reproducible empirical evaluation scripts comparing token savings, compression ratios, and exact roundtrips across multi-domain corpora.
