Dual Planes (Ground + Elevated)

Legend & Taxonomy

Ground Plane (Z=0) — lowercase, PUA E000–E019, cyan stroke
Elevated Plane (Z=25) — UPPERCASE, PUA E800–E819, gold stroke
C₁ᵥ Vertical mirror — {A, M, T, U, V, W, Y}
C₁ₕ Horizontal reflection — {B, C, D, E, K}
C₂ Centrosymmetric inversion — {H, I, N, O, S, X, Z}
C₁ Chiral / asymmetric — {F, G, J, L, P, Q, R}

Each glyph exists in both planes. Chords (multi-character ligatures) also have dual-plane forms. This atlas shows all glyphs currently defined in the repository — it is not claimed to be a complete inventory of all possible RYTT symbols.
